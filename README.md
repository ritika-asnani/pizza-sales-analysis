# Pizza Sales Analysis

This project presents an exploratory SQL analysis of pizza sales data, focusing on understanding order behavior, sales patterns, and revenue distribution.  
The analysis was carried out as a hands-on project to strengthen practical SQL skills using a real-world style dataset.

---

## Dataset
The analysis is based on a pizza sales dataset consisting of four relational tables: orders, order_details, pizzas, and pizza_types.  
These tables capture order timing, pizza attributes, pricing, and quantities sold.

---

## Project Structure

- `01_foundational_overview.sql`  
  Basic sales metrics such as total orders, total revenue, popular pizza sizes, and top-selling pizza types.

- `02_sales_patterns.sql`  
  Analysis of sales distribution across pizza categories, order trends by time of day, and average daily demand.

- `03_revenue_insights.sql`  
  Revenue-focused analysis including contribution percentage, cumulative revenue trends, and top-performing pizzas within each category.

---

## Tools & Technologies
- MySQL  
- SQL (Joins, Aggregations, Subqueries, Window Functions)

---

## Key Insights
- Order volume peaks during evening hours, indicating higher customer demand later in the day.  
- Medium-sized pizzas are the most frequently ordered across the dataset.  
- Revenue is concentrated among a limited number of pizza categories rather than being evenly distributed.  
- Certain pizza types consistently emerge as top revenue contributors within their respective categories.
